# My projects

Everything you make lives here, one folder per project. The chat creates them for you
(`scripts/new_project.py`).

This folder is **yours**: git ignores everything in it except this file, so pulling updates to the kit's
guide never touches your work. `PROGRESS.md` (also written by the chat) remembers where you are in the journey.

Want a backup or to share a project? Ask the chat: "save my projects to GitHub".
