מה יש בערכהWhat's in the kit

ארבעה חלקים, בלי הלחמה. מספיק כדי לבנות משחקים, מוזיקה, שעונים וגאדג'טים מחוברים לאינטרנט.Four parts, no soldering. Enough for games, music, clocks and internet gadgets.

🧠

ESP32ESP32

מחשב זעיר עם שני מעבדים, WiFi ו-Bluetooth. מתחבר ב-USB.A tiny computer with two cores, WiFi and Bluetooth. Connects over USB.

🖥️

מסך OLEDOLED screen

128 על 64 נקודות לבנות. מספיק לציורים, טקסט ואנימציה.128 by 64 white dots. Enough for drawings, text and animation.

🔘

לחיצה, החזקה, לחיצה כפולה. האתגר: לעצב משחק עם כפתור אחד.Tap, hold, double-tap. The challenge: design a game for one button.

שלב 1Stage 1

בונים את הערכהBuild the kit

עקבו אחרי הסרטון והחיבורים. כשמחברים ל-USB, משחק Flappy עולה. אם הציפור עפה כשלוחצים, הכול מחובר נכון.Follow the video and the wiring. Plug it into USB and Flappy starts. If the bird flies when you press, everything is wired right.

בטיחות:Safety: מנתקים את ה-USB לפני שמזיזים חוט. המסך מתחבר ל-3V3, אף פעם לא ל-5V. שום דבר לא אמור להתחמם: אם משהו מתחמם, מנתקים ובודקים את החיבורים.Unplug USB before moving any wire. The screen goes to 3V3, never 5V. Nothing should get warm: if something does, unplug and check the wiring.

כבל USB חייב להעביר נתונים. יש כבלים שרק מטעינים, ונראים בדיוק אותו דבר.The USB cable must carry data. Some cables only charge, and look exactly the same.

שלב 2Stage 2

לומדים לתכנת עם הראש והידייםLearn to program it with your own head and hands

לפני הקסם, כדאי להבין מה קורה בפנים. בשלב הזה מתכנתים את הערכה בעצמכם, כמו פעם: כל שורה אתם כותבים, וכל שגיאה אתם מתקנים. משתמשים ב-MicroPython, שפה ידידותית למתחילים, ובתוכנה פשוטה בשם Thonny.Before the magic, it pays to understand what happens inside. In this stage you program the kit yourself, the old-school way: you write every line and fix every mistake. You use MicroPython, a beginner-friendly language, and a simple program called Thonny.

שלב 3Stage 3

הקסם: מתכנתים עם בינה מלאכותית לצידכםThe magic: program with an AI by your side

עכשיו צ'אט בינה מלאכותית בונה איתכם כל רעיון, ב-C++ כמו של Arduino. ההכנה נעשית פעם אחת, בערך 30 דקות, ובלי שום ידע מוקדם. אחר כך הצ'אט עושה את העבודה ומסביר לכם מה ללחוץ. מומלץ מחשב Windows.Now an AI chat builds any idea with you, in Arduino-style C++. Setup is done once, about 30 minutes, with no prior knowledge. After that the chat does the work and tells you what to click. A Windows computer is recommended.

1

התקינו את VS CodeInstall VS Code

VS Code היא תוכנה לכתיבת קוד, ובתוכה יגור הצ'אט. מורידים מ-VS Code is a program for writing code, and the chat will live inside it. Download from code.visualstudio.com, מריצים את קובץ ההתקנה ולוחצים Next עד הסוף., run the installer and click Next until it finishes.

2

התקינו את GitInstall Git

Git הוא כלי שמעתיק פרויקטים מהאינטרנט למחשב, ומעדכן אותם. מורידים מ-Git is a tool that copies projects from the internet to your computer, and keeps them updated. Download from git-scm.com, מריצים ולוחצים Next בכל המסכים (יש הרבה, ברירות המחדל טובות). אחר כך סוגרים את VS Code ופותחים אותו מחדש., run it and click Next on every screen (there are many; the defaults are fine). Then close VS Code and open it again.

3

הוסיפו צ'אט בינה מלאכותית (אחד מהשניים)Add an AI chat (one of the two)

  • Claude Code: ב-VS Code לוחצים על אייקון ארבעת הריבועים בצד (Extensions), מחפשים "Claude Code", לוחצים Install, ונכנסים עם חשבון Claude.Claude Code: in VS Code click the four-squares icon on the side (Extensions), search "Claude Code", click Install, and sign in with a Claude account.
  • GitHub Copilot: צריך חשבון GitHub חינמי. ב-VS Code לוחצים על אייקון האדם למטה בצד, נכנסים ל-GitHub, פותחים את הצ'אט ובוחרים בו מצב Agent.GitHub Copilot: needs a free GitHub account. In VS Code click the person icon at the bottom of the side bar, sign in to GitHub, open the chat and set it to Agent mode.

עובד כשכותבים בצ'אט hello והוא עונה.It works when you type hello in the chat and it answers.

4

העתיקו את הפרויקט למחשב, בלחיצות בלבדCopy the project to your computer, with clicks only

  1. ב-VS Code לוחצים Ctrl+Shift+P. נפתחת שורת חיפוש למעלה.In VS Code press Ctrl+Shift+P. A search box opens at the top.
  2. כותבים Git: Clone ולוחצים Enter.Type Git: Clone and press Enter.
  3. מדביקים את הכתובת הזו ולוחצים Enter:Paste this address and press Enter: 
    https://github.com/avisalmon/SingleButtonKitBKM.git
  4. בוחרים תיקייה לשמור בה (למשל Documents) ולוחצים Select as Repository Destination.Choose a folder to keep it in (Documents is fine) and click Select as Repository Destination.
  5. כשמופיעה ההודעה למטה, לוחצים Open, ואז Yes, I trust the authors.When the message appears at the bottom, click Open, then Yes, I trust the authors.

בצד שמאל רואים את קבצי הפרויקט, למשל README.md ו-CLAUDE.md.The project's files show on the left, for example README.md and CLAUDE.md.

או: אותו דבר עם הטרמינל (שורת הפקודה)Or: the same with the terminal (the command line)

מה זה טרמינל?What is a terminal?

טרמינל (נקרא גם "שורת פקודה") הוא חלון שבו נותנים למחשב הוראות בכתיבה, במקום ללחוץ עם העכבר. כותבים שורה, לוחצים Enter, והמחשב מבצע. לא צריך לפחד ממנו: הוא רק עושה מה שכותבים לו.A terminal (also called the "command line") is a window where you give the computer instructions by typing, instead of clicking with the mouse. You type a line, press Enter, and the computer does it. Nothing to fear: it only does what you type.

איך פותחים אותו ב-VS CodeHow to open it in VS Code

בתפריט למעלה: Terminal ואז New Terminal. (או המקשים Ctrl+`, המקש שמתחת ל-Esc.) נפתח חלון בתחתית המסך, עם שורה כזו:In the top menu: Terminal, then New Terminal. (Or the keys Ctrl+`, the key under Esc.) A panel opens at the bottom of the screen, with a line like this:

PS C:\Users\you>

השורה הזו נקראת "prompt": המחשב מחכה לפקודה שלכם.That line is called the "prompt": the computer is waiting for your instruction.

איך עובדים איתוHow to use it

  1. לוחצים בתוך חלון הטרמינל כדי שיקבל את ההקלדה.Click inside the terminal panel so it receives your typing.
  2. מעתיקים שורה אחת (כפתור Copy) ומדביקים בטרמינל עם Ctrl+V או קליק ימני.Copy one line (the Copy button) and paste it into the terminal with Ctrl+V or a right-click.
  3. לוחצים Enter, ומחכים עד שמופיעה שוב שורת ה-prompt. זה הסימן שהפקודה הסתיימה.Press Enter, and wait until the prompt line appears again. That's the sign the instruction finished.
  4. טקסט אדום = שגיאה. לא נורא: מעתיקים אותו ושולחים לצ'אט, והוא יסביר.Red text = an error. No big deal: copy it into the chat and it will explain.

ארבע השורות שמעתיקות ופותחות את הפרויקט, אחת אחרי השנייה:The four lines that copy and open the project, one after the other:

mkdir C:\kit
cd C:\kit
git clone https://github.com/avisalmon/SingleButtonKitBKM.git
code SingleButtonKitBKM

מה כל שורה עושה: יוצרת תיקייה בשם kit, נכנסת אליה, מעתיקה לתוכה את הפרויקט, ופותחת אותו ב-VS Code.What each line does: makes a folder called kit, goes into it, copies the project into it, and opens it in VS Code.

5

פתחו את הצ'אט וכתבו:Open the chat and type:

תגיד לי מה לעשותTell me what to do

זהו. מכאן הצ'אט מוביל: מתקין Python והכלים, מוצא את הערכה, בודק את המסך, הכפתור והזמזם, ובונה איתכם את התוכנית הראשונה. חוזרים מחר? כותבים את אותו משפט, והוא ממשיך מאיפה שעצרתם.That's it. From here the chat leads: it installs Python and the tools, finds the kit, checks the screen, button and buzzer, and builds your first program with you. Back tomorrow? Type the same sentence and it continues where you stopped.

מעכשיו לא צריך להקליד פקודותFrom now on you don't type commands

הצ'אט מריץ את הפקודות בעצמו, בטרמינל של VS Code. לפני כל פקודה הוא מראה מה הוא רוצה להריץ ושואל אם מותר (Allow / Run). קוראים, ולוחצים לאשר. אם משהו לא ברור, שואלים אותו: "מה הפקודה הזו עושה?"The chat runs the commands itself, in VS Code's terminal. Before each one it shows what it wants to run and asks permission (Allow / Run). Read it, and click to approve. If something is unclear, ask it: "What does this command do?"

תמיד מתעדכןAlways up to date

המדריך משתפר כל הזמן. בכל פעם שפותחים צ'אט, הוא מושך קודם את הגרסה החדשה. הפרויקטים שלכם נשמרים בתיקייה my_projects, ועדכונים לא נוגעים בה.The guide keeps improving. Every session, the chat first pulls the newest version. Your projects live in my_projects, which updates never touch.

Flappy תמיד חוזרFlappy always comes back

העלאת תוכנית מחליפה את המשחק שעל הערכה. כותבים "תחזיר את פלאפי" והוא חוזר, בדיוק כמו שהיה.Uploading a program replaces the game on the kit. Type "Restore Flappy" and it comes back, exactly as it was.

להורים ולמוריםFor parents and teachers

לשירותי בינה מלאכותית יש מגבלות גיל: מבוגר פותח את החשבון ונשאר בסביבה. הצ'אט לא מבקש פרטים אישיים. לסשנים ארוכים בדרך כלל צריך מנוי בתשלום לשירות הבינה המלאכותית.AI services have age limits: an adult opens the account and stays nearby. The chat never asks for personal details. Long sessions usually need a paid plan for the AI service.
